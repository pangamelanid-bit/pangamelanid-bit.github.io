--------------------------------------------------------------------------------
🌐 CARA PUBLISH KE INTERNET SECARA GRATIS (RP 0)
--------------------------------------------------------------------------------
PILIHAN A — Vercel (Paling Mudah & Kencang):
1. Buka https://vercel.com lalu daftar/login gratis (bisa pakai akun Google).
2. Upload/drag folder "PAN-Gamelan-Website" ke dashboard Vercel.
3. Website Anda langsung live di internet dengan alamat gratis, misalnya:
   `pangamelan.vercel.app` (lengkap dengan HTTPS/SSL gratis selamanya).

PILIHAN B — GitHub Pages:
1. Buat repository baru di GitHub (misal: `pan-gamelan-web`).
2. Upload seluruh isi folder ini.
3. Buka menu Settings -> Pages -> pilih branch "main" -> Save.
4. Website langsung aktif di `username.github.io/pan-gamelan-web`.
